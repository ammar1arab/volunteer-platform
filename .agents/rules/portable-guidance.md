# Portable project guidance

Canonical behavior lives in `.agents`, independent of a specific editor. Keep project paths, stack, commands, and product conventions in the project profile.

IDE adapters route to the canonical files. Preserve existing adapter settings and metadata. Do not copy competing rule bodies into multiple editors.

When moving to a new project, update the project profile and review domain-specific skills. Generic guidance must not imply permissions, override user instructions, or mandate unavailable tools.
